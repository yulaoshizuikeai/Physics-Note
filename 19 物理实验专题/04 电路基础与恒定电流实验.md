## 实验一：探究影响平行板电容器电容的因素

### 1. 实验仪器：静电计的工作原理
* **构造**：金属球、金属杆、金属指针和金属外壳（外壳通常接地）。
* **测量本质**：静电计本质上是一只能够测量**超高内阻、微小电荷下静电电势差**的专用静电仪表。
* **偏角判据**：静电计指针所带电荷与金属杆互斥而偏转。**指针张开的角度 $\theta$ 越大，表示金属球与外壳之间的电势差 $U$ 越大**！

```
        平行板电容器                   静电计
       ┌──┐     ┌──┐                  ┌───┐ 金属球
       │  │     │  │                  │   │
       │  │     │  │──────────────────┤   │
       │  │     │  │                  │ │ │ 金属杆
       │  │     │  │                  │ ╱ │ 指针偏角 θ
       └──┘     └──┘                  └───┘ 
         │        │                     │
        接地     充电后断开           外壳接地
```

### 2. 实验核心物理规律
平行板电容器电容决定式与定义式：
$$C = \frac{\varepsilon_r S}{4\pi k d}, \quad C = \frac{Q}{U} \implies U = \frac{4\pi k d}{\varepsilon_r S} Q$$
* **实验前提条件**：用电源对平行板电容器充电后，**拔掉电源插头（断开电源）**。
* **物理约束**：此时电容器两极板所带的**电荷量 $Q$ 保持恒定不变**！

### 3. 三大控制变量操作与现象分析

| 实验操作步骤 | 物理量变化 | 电容 $C$ 的响应 | 极板间电势差 $U$ 变化 | 静电计指针偏角 $\theta$ 现象 |
| :--- | :---: | :---: | :---: | :--- |
| **增大两板间距 $d$** | $d \uparrow$ | $C = \frac{\varepsilon_r S}{4\pi k d} \downarrow$ | $U = \frac{Q}{C} \uparrow$ | 指针张角**显著增大** |
| **减小两板正对面积 $S$**<br>（平行错开两极板） | $S \downarrow$ | $C = \frac{\varepsilon_r S}{4\pi k d} \downarrow$ | $U = \frac{Q}{C} \uparrow$ | 指针张角**显著增大** |
| **两极板间插入电介质板**<br>（如有机玻璃或陶瓷板） | $\varepsilon_r \uparrow$ | $C = \frac{\varepsilon_r S}{4\pi k d} \uparrow$ | $U = \frac{Q}{C} \downarrow$ | 指针张角**显著变小** |

> [!TIP]
> **拓展思考：极板间电场强度 $E$ 的变化**
> 当保持电荷量 $Q$ 恒定时：
> $$E = \frac{U}{d} = \frac{Q}{C d} = \frac{4\pi k Q}{\varepsilon_r S}$$
> 由此可见：**仅改变极板间距 $d$ 时，极板间的匀强电场场强 $E$ 保持恒定不变**！

## 实验二：观察电容器的充、放电现象

### 1. 实验电路与传感器采集系统
* 利用单刀双掷开关控制电路：
  - 开关打到触点 1：直流电源对电容器充电；
  - 开关打到触点 2：电容器通过电阻 $R$ 放电。
* 电路中接入微电流传感器和电压传感器，通过数据采集器与计算机连接，实时捕捉毫秒级的充放电瞬态波形。

```
                   1 ┌──○ S (单刀双掷)
        ┌────────────○
        │            │
      ┌─┴─┐          └──○ 2
      │ E │             │
      └─┬─┘             ├───────┐
        │             ┌─┴─┐   ┌─┴─┐
        │             │ C │   │ R │
        │             └─┬─┘   └─┬─┘
        └───────────────┴───────┘
```

### 2. 充放电瞬态特性对比

| 物理过程 | 电路能量转化 | 电流 $I(t)$ 变化规律 | 电容两端电压 $U_C(t)$ 变化 |
| :---: | :---: | :--- | :--- |
| **充电过程** | 电源电能转化为电容器电场能 | 从最大初始电流 $I_0 = \frac{E}{R}$ 指数衰减至 0 | 从 0 指数上升至电源电动势 $E$ |
| **放电过程** | 电容器电场能转化为电阻内能 | 产生反向电流，从 $-I_0$ 指数衰减至 0 | 从电动势 $E$ 指数衰减至 0 |

### 3. 微元累积法求电荷量 $Q$ 与计算电容 $C$
由电流的定义式 $I = \frac{\Delta q}{\Delta t} \implies \Delta q = I \cdot \Delta t$。
* 在计算机绘制出的 $I - t$ 图像中，**图线与时间轴 $t$ 所包围的面积，在物理上严格表示电容器充电（或放电）完成时所存储（或释放）的总电荷量 $Q$**！
  $$Q = \sum I_i \Delta t_i = \int_0^\infty I(t) \, dt$$
* **计算电容**：
  $$C = \frac{Q}{U} = \frac{\text{图线下围总面积}}{E}$$

## 实验三：探究决定导线电阻的因素（探究电阻定律）

### 1. 物理模型与控制变量法
探究导体电阻 $R$ 与其材料、长度 $l$、横截面积 $S$ 的定量依赖关系：
1. **探究 $R$ 与 $l$ 的关系**：选取**材料相同、横截面积相同**但长度不同的金属合金丝，测其阻值 $\implies R \propto l$；
2. **探究 $R$ 与 $S$ 的关系**：选取**材料相同、长度相同**但直径不同的金属合金丝，测其阻值 $\implies R \propto \frac{1}{S}$；
3. **探究 $R$ 与材料的关系**：选取**长度相同、横截面积相同**但材料不同（如康铜、镍铬合金）的金属丝，测其阻值 $\implies$ 阻值差异显著。
* **实验定律总结**：
  $$R = \rho \frac{l}{S}$$
  式中 $\rho$ 为材料的电阻率（反映材料导电性能的微观本构参数）。

## 实验四：测量金属的电阻率

### 1. 实验原理与数学公式
均匀金属丝截面视为圆形，横截面积 $S = \frac{\pi d^2}{4}$。
由电阻定律 $R = \rho \frac{l}{S}$，整理可得金属电阻率计算公式：
$$\rho = \frac{R S}{l} = \frac{\pi d^2 R}{4l}$$

### 2. 测量物理量与仪器分工矩阵

| 物理量 | 符号 | 测量仪器 | 测量与规范要求 |
| :---: | :---: | :---: | :--- |
| **金属丝直径** | $d$ | **螺旋测微器** | 在金属丝的**不同位置测量 3 次**取平均值；必须估读到千分位（$0.001\,\text{mm}$）。 |
| **有效长度** | $l$ | **毫米刻度尺** | 金属丝拉直后，测量**接入电路的两接线柱之间**的有效长度（切勿将接线柱内部夹紧包裹部分算入！），测量 3 次取平均。 |
| **金属丝电阻** | $R$ | **伏安法回路** | 电流表与电压表读数，多次改变滑片位置记录多组 $(U, I)$，用 $R = \frac{\Delta U}{\Delta I}$ 拟合计算。 |

### 3. 电路设计判据
* **测量电路（外接法）**：金属丝电阻较小（一般 $1\,\Omega \sim 15\,\Omega$），远小于电压表内阻（$R_V \approx 3\,\text{k}\Omega$），满足 $R_x \ll R_V$，采用**电流表外接法**；
* **控制电路（限流式优先）**：滑动变阻器最大阻值与金属丝相当时，选用**限流式接法**以降低功耗。

## 实验五：描绘小灯泡的伏安特性曲线

### 1. 实验现象与物理本质
小灯泡灯丝由钨制成。随着电压升高，电流增大，电功率增大，灯丝温度剧烈升高（可达 $2000^\circ\text{C}$ 以上）。
* 金属的电阻率随温度升高而显著增大，导致灯丝电阻随电压升高而变大；
* 在 $I - U$ 图像中，图线呈现**逐渐向下弯曲的非线性形态**（图线上各点割线斜率 $\frac{I}{U} = \frac{1}{R}$ 逐渐减小）。

```
        I (电流)
        ▲
        │         ┌─────────── 曲线向下弯曲 (电阻 R 随电压升高而增大)
        │       .'
        │     .'
        │   .'
        │ .'
        └───────────────────► U (电压)
```

### 2. 电路选型两大刚性铁律
1. **控制电路必须采用【分压式接法】**：描绘伏安特性曲线必须获取从小灯泡**完全熄灭（$U = 0$）到正常发光**的全量程连续数据；限流电路存在非零截止下限，无法调零。
2. **测量电路必须采用【电流表外接法】**：小灯泡正常工作电阻仅约 $10\,\Omega$，冷态甚至小于 $2\,\Omega$。电阻极小，外接法分流误差可忽略不计；若选内接法，电流表内阻将带来高达 $30\%$ 以上的严重误差。

## 实验六：测定电池的电动势和内阻

### 1. 伏安法（电流表 + 电压表 + 滑动变阻器）

#### 方案 A：电流表相对电源外接法（测量干电池的标准规范）
* **电路结构**：电压表直接并联在电源两端测路端电压，电流表测滑动变阻器电流。
* **误差根源**：电压表有限内阻分流 $I_{\text{总}} = I + \frac{U}{R_V}$。
* **戴维南等效电源分析**：
  $$\begin{cases}
  E_{\text{测}} = \dfrac{R_V}{r + R_V} E_{\text{真}} < E_{\text{真}} \\[1em]
  r_{\text{测}} = \dfrac{r \cdot R_V}{r + R_V} < r_{\text{真}}
  \end{cases}$$
* **$U - I$ 图像特征**：
  - 纵轴截距（断路电压）：$U = E_{\text{测}} < E_{\text{真}}$，**电动势测量值偏小**；
  - 横轴截距（短路电流）：当 $U = 0$ 时电压表分流为 0，**短路电流测量值严格准确**（$I_{\text{短}} = E/r$），图线与真实直线交于横轴；
  - 斜率绝对值：$|k| = r_{\text{测}} < r_{\text{真}}$，**内阻测量值偏小**。

#### 方案 B：电流表相对电源内接法
* **误差根源**：电流表内阻分压 $U_{\text{路端}} = U + I R_A$。
* **等效结论**：
  $$\begin{cases}
  E_{\text{测}} = E_{\text{真}} \\[0.5em]
  r_{\text{测}} = r_{\text{真}} + R_A > r_{\text{真}}
  \end{cases}$$
* **适用场景**：由于普通干电池内阻极小（约 $0.5\,\Omega$），电流表内阻本身有 $0.5\,\Omega$，相对误差高达 $100\%$，**普通干电池严禁采用内接法**！内接法仅适用于测量内阻极大的水果电池（内阻几千欧姆）。

---

### 2. 变换法测量：安阻法与伏阻法的图像线性化

#### ① 安阻法（电流表 A + 电阻箱 R）
由闭合电路欧姆定律：
$$E = I(R + r) \implies \frac{1}{I} = \frac{1}{E} R + \frac{r}{E}$$
* 绘制 $\frac{1}{I} - R$ 线性图像；
* 斜率 $k = \frac{1}{E} \implies E = \frac{1}{k}$；
* 纵截距 $b = \frac{r}{E} \implies r = \frac{b}{k}$。

#### ② 伏阻法（电压表 V + 电阻箱 R）
由闭合电路欧姆定律：
$$E = U + \frac{U}{R} r \implies \frac{1}{U} = \frac{r}{E} \left(\frac{1}{R}\right) + \frac{1}{E}$$
* 绘制 $\frac{1}{U} - \frac{1}{R}$ 线性图像；
* 纵截距 $b = \frac{1}{E} \implies E = \frac{1}{b}$；
* 斜率 $k = \frac{r}{E} \implies r = \frac{k}{b}$。

## 典型高考电学避坑指南

| 常见易错认知 | 科学判断 | 规范物理本质 |
| :--- | :---: | :--- |
| 平行板电容器接在电源上时，拔大板间距会导致静电计指针偏角变大 | **×** | 致命审题错误！始终连接电源时，极板间电势差 $U$ 恒等于电源电动势，指针偏角绝对不变！只有断开电源后电荷量恒定时偏角才增大。 |
| 测金属丝电阻率时，将连接在接线柱螺丝内部的金属丝总长计入 $l$ | **×** | 严重违规！螺丝内部被金属垫片压死，没有电流流经这段电阻，必须只测量两接线柱之间的露在外部的有效长度。 |
| $U - I$ 图像中，内阻计算直接套用公式 $r = \frac{U}{I}$ | **×** | 概念混淆！$U/I$ 是外电阻 $R$；电源内阻是图线的斜率绝对值：$r = \left|\frac{\Delta U}{\Delta I}\right|$！ |
