# 物理矢量 SVG 设计与多模态视觉核验协议

## 1. SVG 画布、布局与防重叠设计
- **统一视口标准**：统一使用 `viewBox="0 0 780 370"`，兼顾 VitePress 移动端自适应响应与桌面端高保真展示。
- **专业配色体系**：采用深色 Slate 顶部标题条、白色/淡蓝双列卡片、标准 Tailwind 物理矢量色（蓝色受力/电场、红色重力/极值/电流、绿色速度/等势面、橙色角度/中间量）。
- **局部坐标系防叠字准则**：
  - 多卡片纵向排布时，**必须使用 `<g transform="translate(0, Y)">` 建立独立局部坐标系**，严禁在根坐标系中直接写入硬编码的绝对 Y 坐标，以杜绝多段文本与公式相互重叠。
  - 几何图形两端标注文本与卡片外框之间至少保留 10px 的安全留白，避免边缘截断。

## 2. 闭环多模态视觉化质检流程
- **强制光栅化渲染**：
  - 任何新增或重构的物理 SVG 图解，不得仅依靠代码审查，必须调用 Playwright / 无头 Chrome 渲染脚本将 SVG 输出为 2x 高清 PNG。
- **多模态视觉质检核验**：
  - 使用 `view_file` 对渲染出的 PNG 截图进行视觉质检：
    1. 检查文字两端是否被卡片边框截断；
    2. 检查矢量箭头是否穿透文字或遮挡公式；
    3. 检查天体、粒子等图元内部的标注字符是否与边缘线条重合。
  - 若发现瑕疵，立即微调 SVG 坐标，重新光栅化复验，直到视觉达到教材级出版品质。
