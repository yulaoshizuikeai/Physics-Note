## 系统、内力与外力

在应用守恒定律之前，必须严谨界定物理系统的边界：
- **系统（System）**：存在相互作用的两个或两个以上物体所构成的力学集合体；
- **内力（Internal Forces）**：系统内部各物体之间的相互作用力。
  - **核心性质**：根据牛顿第三定律，**系统内部的内力总是成对出现、大小相等、方向相反**。因此，系统所有内力的矢量和恒等于零（$\sum \vec{F}_{\text{内}} \equiv \mathbf{0}$），内力绝不能改变系统整体的总动量！
- **外力（External Forces）**：系统以外的物体对系统内部物体施加的作用力。

## 动量守恒定律的推导

设系统由两个相互碰撞的物体 $A$（质量 $m_1$）和 $B$（质量 $m_2$）组成，碰撞前速度分别为 $\vec{v}_1, \vec{v}_2$，碰撞后速度分别为 $\vec{v}_1', \vec{v}_2'$：
1. 在极短的碰撞时间 $\Delta t$ 内，两物体受到彼此的碰撞内力分别为 $\vec{F}_{21}$（$B$ 对 $A$）和 $\vec{F}_{12}$（$A$ 对 $B$）；
2. 分别对两物体应用**动量定理**：
   - 对物体 $A$：$\vec{F}_{21} \Delta t = m_1\vec{v}_1' - m_1\vec{v}_1$
   - 对物体 $B$：$\vec{F}_{12} \Delta t = m_2\vec{v}_2' - m_2\vec{v}_2$
3. 根据**牛顿第三定律**：$\vec{F}_{21} = -\vec{F}_{12} \implies \vec{F}_{21} + \vec{F}_{12} = \mathbf{0}$；
4. 将两式相加：
   $$(\vec{F}_{21} + \vec{F}_{12}) \Delta t = (m_1\vec{v}_1' + m_2\vec{v}_2') - (m_1\vec{v}_1 + m_2\vec{v}_2) = \mathbf{0}$$
   $$\therefore m_1\vec{v}_1 + m_2\vec{v}_2 = m_1\vec{v}_1' + m_2\vec{v}_2'$$
即系统的总动量在相互作用前后保持恒定不变！

## 动量守恒定律的内容与三大成立判据

### 1. 定律内容
**如果一个系统不受外力，或者所受外力的矢量和为零，这个系统的总动量保持不变。**

### 2. 高考三大成立判据（从严格到局部）

| 守恒层级 | 成立判据与物理条件 | 适用典型物理场景 |
| :--- | :--- | :--- |
| **一、严格守恒** | 系统**完全不受外力**，或者系统所受**合外力严格为零**（$\sum \vec{F}_{\text{外}} = \mathbf{0}$）。 | 冰面滑冰者互推、光滑水平面上的两滑块弹簧系统。 |
| **二、近似守恒** | 系统所受合外力不为零，但**相互作用的内力远大于外力**（$F_{\text{内}} \gg F_{\text{外}}$），且作用时间 $\Delta t$ 极短，外力的冲量 $F_{\text{外}}\Delta t \approx \mathbf{0}$。 | **爆炸、枪炮射击、高速碰撞、微粒散射**。在几毫秒内，重力和摩擦力冲量几乎为零。 |
| **三、单方向（分动量）守恒** | 系统整体所受合外力不为零，但**在某一特定方向（如水平 $x$ 轴）上合外力为零**（$\sum F_{\text{外}x} = 0$）。 | **滑块沿斜面下滑、抛体在空中水平爆炸**。虽然竖直方向受重力和支持力不平衡，但水平方向总动量严格守恒！ |

## 动量守恒定律的四大数学表达形式

1. **状态式**：
   $$p_1 + p_2 + \dots + p_n = p_1' + p_2' + \dots + p_n' \quad (\text{即 } \vec{p}_{\text{初}} = \vec{p}_{\text{末}})$$
2. **转移式（增减守恒）**：
   $$\Delta\vec{p}_1 = -\Delta\vec{p}_2 \quad (\text{即 } \Delta p_{1\text{增}} = \Delta p_{2\text{减}})$$
   系统内一部分动量的增加量，严格等于其余部分动量的减少量。
3. **变化量式**：
   $$\Delta\vec{p}_{\text{总}} = \mathbf{0}$$
4. **时间积分位移式（人船模型微元累积）**：
   若系统由两静止物体组成（初始总动量为零），由于任一瞬时 $m_1 v_1(t) = m_2 v_2(t)$：
   两边对时间积分：$\int m_1 v_1 dt = \int m_2 v_2 dt$，得到**空间位移守恒定律**：
   $$m_1 x_1 = m_2 x_2$$
   - 质量大的物体移动距离小，质量小的物体移动距离大；
   - 极其适用于求解“人走船退”、“人在气球软梯上爬行”、“小车内滑块滑动”等无摩擦系统的空间相对位移。

## 典型考点与易错辨析

> [!WARNING]
> **高考常考认知误区**
> - [×] “只要系统内有摩擦力，系统的动量就一定不守恒。”（大错特错！摩擦力如果是系统内部各物体间的相互作用力（内力），它只会使系统的机械能转化为内能耗散，但**对系统总动量没有任何破坏作用，动量依然严格守恒**！）
> - [×] “在斜面上滑下的小球和小车系统，动量在任何方向都守恒。”（错误！竖直方向支持力与重力合力不为零，只有在水平方向不受外力时，水平方向分动量守恒）
> - [√] 动量守恒定律不仅适用于低速宏观机械运动，而且在高速相对论物理、微观量子物理中依然严格普适，是自然界最基本的守恒定律之一。
